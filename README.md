#### Как запустить

Проект запускается в **Swift Playground** с помощью кнопочки Execute Playground, после нажатия на которую появится интерфейс для взаимодействия

#### Поддерживаемые команды

Добавить книгу
Изменить книгу
Удалить книгу
Найти книги
Вывести историю операций
Вывести список книг (различным образом с помощью сортировок)
Выход

#### Пример сценария

Добавить книгу (заполнить Title/Author/Genre, опционально Year/Tags)
Вывести список книг (проверить, что книга появилась)
Найти книги (например, по author или tags)
Изменить книгу (ввести id и изменить, например, title или year)
Вывести историю операций (увидеть add/update)
Выйти из программы
